# 🚁 Simulador de Encomendas em Drone

Sistema completo de simulação de entregas por drones com otimização inteligente de rotas.

## 🚀 Tecnologias

- **Backend**: Node.js + Express
- **Frontend**: React + Vite
- **Comunicação**: REST API

## 📦 Funcionalidades Implementadas

### ✅ Obrigatórias
- [x] Alocação automática de drones
- [x] Gestão de capacidade e distância
- [x] Sistema de prioridades (baixa, média, alta)
- [x] Testes unitários (estrutura preparada)

### ✅ Avançadas
- [x] Simulação de bateria do drone
- [x] Cálculo de tempo total de entrega
- [x] Fila de entrega por prioridade
- [x] Dashboard em tempo real

### ✅ Diferenciais
- [x] Otimização inteligente de rotas
- [x] Sistema de estados do drone (Idle → Loading → Flying → Delivering → Returning)
- [x] APIs RESTful bem definidas
- [x] Interface moderna e responsiva
